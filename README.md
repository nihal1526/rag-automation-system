# n8n RAG AI Agent

AI-powered RAG automation platform built with n8n, OpenAI, MongoDB, FastAPI, and vector databases.

## 🚀 Features
- AI Agent Workflows
- OpenAI Integration
- MongoDB Chat Memory
- Knowledge Base Search
- RAG Pipeline
- Vector Database Support
- FastAPI Backend
- Docker Deployment

## 🛠 Tech Stack
- n8n
- OpenAI
- MongoDB
- FastAPI
- Qdrant / ChromaDB
- Docker
